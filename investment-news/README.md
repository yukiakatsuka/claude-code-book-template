# 投資ニュース

過去24時間の投資関連ニュースをまとめて表示するWebアプリ。  
iPhone（Safari）でホーム画面に追加してアプリとして使用できます。

**公開URL:** https://yukiakatsuka.github.io/investment-news/news.html

---

## 機能

- アプリを開くと自動で最新ニュースを取得
- NHKの複数カテゴリから過去24時間以内のニュースを収集
- 投資に関連するキーワードを含む記事を自動フィルタリング
- マッチしたキーワードをタグとして表示
- 記事タイトルをタップすると元記事へ遷移
- 「更新」ボタンで手動再取得

## ニュースソース

| フィード | URL | フィルター |
|---------|-----|-----------|
| NHK経済 | nhk.or.jp/rss/news/cat6.xml | なし（全件表示） |
| NHKビジネス | nhk.or.jp/rss/news/cat5.xml | なし（全件表示） |
| NHK政治 | nhk.or.jp/rss/news/cat4.xml | キーワードフィルター |
| NHK主要 | nhk.or.jp/rss/news/cat0.xml | キーワードフィルター |

NHK経済・NHKビジネスはカテゴリ自体が投資関連のため全件表示。  
NHK政治・NHK主要は下記キーワードにマッチした記事のみ表示。

## 技術構成

```
フロントエンド:  Vanilla JS + Canvas 2D API（ビルドステップなし）
RSSプロキシ:    rss2json.com（無料・CORS対応・JSON変換）
ホスティング:   GitHub Pages（無料）
```

**ホスティングコスト: ¥0/月**

### データフロー

```
ブラウザ
  └─ fetch → api.rss2json.com
                └─ fetch → NHK RSSフィード
                              └─ XMLをJSONに変換して返却
  └─ 24時間フィルター・キーワードフィルター
  └─ 日時降順ソート・重複排除
  └─ カード形式で表示
```

## ファイル構成

investment-news/

## iPhoneでのインストール方法

1. SafariでURLを開く
2. 画面下部の共有ボタン（□↑）をタップ
3. 「ホーム画面に追加」を選択
4. 「追加」をタップ

ホーム画面からアプリと同じ感覚で起動できます。

## ローカルでの開発・動作確認

```bash
# Node.js が必要
npx http-server . -p 8080 --cors

# ブラウザで開く
open http://127.0.0.1:8080/news.html
```

## カスタマイズ

### キーワードの追加

`news.js` の `INVESTMENT_KEYWORDS` 配列に追記するだけです。

```js
const INVESTMENT_KEYWORDS = [
  // 既存のキーワード...
  '新しいキーワード',
];
```

### フィードの追加

`news.js` の `FEEDS` 配列にRSSフィードを追加します。

```js
const FEEDS = [
  // 既存のフィード...
  {
    name: '表示名',
    url: 'https://example.com/rss.xml',
    color: '#ff6600',   // バッジの色
    noFilter: false,    // true にするとキーワードフィルターをスキップ
  },
];
```

> **注意:** rss2json.com の無料枠は1フィードあたり最大20件・リクエスト数に上限があります。  
> フィードを増やしすぎるとレートリミットに達する場合があります。

## 制約・注意事項

- 週末・祝日は投資関連ニュースが少なく表示件数が減ることがあります
- rss2json.com の無料枠には利用制限があります（個人利用の範囲で十分）
- NHK RSSは最新20件のみ配信のため、取得できるのは各フィード最大20件です
